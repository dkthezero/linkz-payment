UX Prototype Hub

Static HTML prototypes for the customer journey mapped in arch/model.c4 ux view.

  1. Pick a seat — browse the seat map and select an available seat.
  2. Proceed to payment — review the reservation summary before checking out.
  3. Pay (hosted checkout) — complete the payment on the provider’s hosted page.
  4. Receive invoice + e-ticket — download the invoice and e-ticket after confirmation.
0. Login / Landing 1. Seat Map → 2. Checkout Review 3. Hosted Payment 4. Confirmation + Ticket

These pages are intentionally lightweight and self-contained. Open any file directly in a browser to preview the flow.
